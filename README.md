# Frontend Practice Projects

This repository contains a collection of frontend projects built while learning and practicing HTML and CSS concepts.

The projects focus on responsive design, layouts, animations, UI creation, and styling techniques.

---

## Projects Included

| Project | Description |
|---|---|
| `A-magazine-article-main` | Styled magazine/article webpage |
| `Syntara-dashboard-UI-master` | Personal dashboard UI concept |
| `animated-penguin-main` | CSS-based animated penguin |
| `css-cat-art-main` | Cat illustration created using pure CSS |
| `responsive-city-skyline-main` | Responsive skyline design using CSS |
| `survey-form-main` | Responsive survey form project |
| `tribute-page-nikola-tesla-main` | Tribute webpage dedicated to Nikola Tesla |
